# Billing System — OOP Mini Project

A console-based billing system developed using Python Object-Oriented Programming concepts.

## Features

- Product class
- Bill class
- Add multiple products
- Quantity and price calculation
- Subtotal calculation
- 18% tax calculation
- Final bill in tabular format
- Date and time on the bill
- Input validation

## OOP Concepts Used

- Classes
- Objects
- Constructors
- Methods
- Encapsulation through class structure
- Object interaction

## Run

```bash
python billing_system.py
```
