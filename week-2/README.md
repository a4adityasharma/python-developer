# Week 2 — Data Structures & File Handling

This folder contains the practice exercises, assignments, and mini-project completed as part of Week 2 of the Skill Nexis Python Programming Internship.

## Topics Covered

- Lists
- Tuples
- Sets
- Dictionaries
- File Input/Output
- CSV Files
- JSON Files
- Exception Handling
- CRUD Operations

## Practice Questions

1. List CRUD operations
2. Word frequency using a dictionary
3. Pattern printing using nested loops
4. Finding the largest and smallest number in a list
5. Sorting using `sort()` and a lambda key

## Assignments

### 1. Contact Book

Dictionary-based contact management system with:

- Add
- Search
- Update
- Delete

### 2. Word Counter from Text File

Reads a text file and counts:

- Words
- Lines
- Characters

### 3. JSON File Reader

Loads JSON data from a file and displays it in formatted output.

## Mini Project — Student Management System

A CSV-based student management system that stores:

- Student name
- Roll number
- Marks

Features:

- Add student
- Delete student
- Search student
- Display students
- Permanent storage in CSV

## How to Run

Use Python 3.

Examples:

```bash
python practice/01_list_crud.py
python assignment-1-contact-book/contact_book.py
python assignment-2-word-counter/word_counter.py
python assignment-3-json-reader/json_reader.py
python mini-project-student-management/students.py
```

For the file-based programs, run them from their respective folders so their sample files are found correctly.
