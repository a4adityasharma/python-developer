# Employee Data Analysis — Week 4 Capstone

This project is the selected Week 4 capstone for the Skill Nexis Python Programming Internship.

## Objective

Analyze an employee CSV dataset using Pandas.

## Tasks Implemented

- Load employee data from CSV
- Calculate average salary
- Count employees by department
- Filter employees above a salary threshold
- Export filtered results to a new CSV file

## Technologies

- Python
- Pandas
- CSV

## Installation

Install Pandas:

```bash
pip install pandas
```

## Run

```bash
python employee_data_analysis.py
```

The program reads:

```text
employees.csv
```

and generates:

```text
employees_above_threshold.csv
```

## Dataset

A small sample employee dataset is included so that the project can be run immediately. It is intended for demonstrating the required data-processing workflow.
