# Week 1 — Python Basics & Control Structures

This folder contains the assignments and mini-project completed as part of **Week 1** of the Skill Nexis Python Programming Internship.

## Topics Covered

* Print, Input and Data Types
* Operators
* Conditional Statements
* Loops
* Functions and Modules
* String and List Manipulation

## Assignments

### 1. Temperature Converter

A Python program that converts temperatures between Celsius and Fahrenheit.

**Features:**

* Celsius to Fahrenheit conversion
* Fahrenheit to Celsius conversion
* Function-based implementation

### 2. Student Grade Calculator

A Python program that accepts student marks, calculates the average, and assigns a corresponding grade.

**Features:**

* Accept marks as input
* Calculate average marks
* Assign grades using conditional statements

### 3. Even/Odd & Prime Number Checker

A Python program that checks whether a given number is even or odd and whether it is prime.

**Features:**

* Even/odd checking
* Prime number checking
* User input validation

## Mini Project — Simple ATM Simulator

A console-based ATM simulator developed using Python.

### Features

* PIN-based user authentication
* Check account balance
* Deposit money
* Withdraw money
* Input validation
* Insufficient balance handling
* Limited login attempts
* Menu-driven interface

### Concepts Used

* Variables and data types
* User input
* Conditional statements
* `while` loops
* Functions
* Exception handling
* Global variables
